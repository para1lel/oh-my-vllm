# Rust 代码

Rust 负责服务, 调度器和逻辑 KV cache.
Python 进程准备 token 并返回 worker 结果.

使用 DEALER socket 和 msgpack 协议进行进程通信.

先验证请求和输出, 再提交状态.
只发布已验证的前缀. 在同一事务中分配关联的模型状态分组.

取消与 worker 替换必须释放相关状态.

API, CLI, 流式事件和资源限制遵守运行时契约.
使用小函数和清晰名称. 函数和模块定义之间留空行.

Rust 行宽不超过 100 列.
每个 unsafe 块前添加 `// SAFETY:` 注释, 写明安全依据.

新增测试前, 向用户说明必要性.
执行适用的测试和 hooks. 不在项目文件中记录测试结果.
