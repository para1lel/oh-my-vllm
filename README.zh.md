# oh-my-vllm

本项目提供在单张 NVIDIA B200 上运行 Qwen3.8-27B-FP8 的 Rust 服务.
Python worker 加载模型, 执行文本, 图片和视频推理.
支持普通解码或 MTP4, 并提供约束解码.

安装, 命令和 HTTP 请求见[服务指南](docs/serving.zh.md).

[English](README.md) · [贡献流程](CONTRIBUTING.zh.md)

### 端到端 HTTP

请求使用文本输入, 贪心采样, 且不复用前缀缓存.
调度器 token 预算为 32768. 最多同时运行四个请求.
缓存容量为 1024 个 FA block 和 128 个 GDN slot.

每种模式对每种 batch size 运行一个预热 batch, 每请求输入 64 个 token, 输出 16 个 token.
每种配置正式测量一次. 计时前构造 prompt 文本.

HTTP 时间包含请求线程创建, 服务端请求准备, 排队, 推理, 传输, JSON 解析及线程退出.
Roofline 时间累加记录的 trace 中各 serving 算子下界, 使用实测 MTP 接受数.
效率为 `roofline_seconds / HTTP_seconds`.
