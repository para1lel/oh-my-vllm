# oh-my-vllm

本项目提供在单张 NVIDIA B200 上运行 Qwen3.8-27B-FP8 的 Rust 服务.
Python worker 加载模型, 执行文本, 图片和视频推理.
支持普通解码或 MTP4, 并提供约束解码.

安装, 命令和 HTTP 请求见[服务指南](docs/serving.zh.md).

[English](README.md) · [贡献流程](CONTRIBUTING.zh.md)

## GPU 执行

Worker 使用[算子调度](docs/execution.zh.md).
包含 prefill 的 Execute 对其全部分片使用 Eager 执行.
仅含 decode 的 Execute 使用相同 native 算子的 CUDA Graph 录制和重放.
数值检查使用短输入, 单次迭代的[全模型 logits 对照](docs/operators/evaluation.zh.md), 参考值由 PyTorch 直接进行 FP64 计算.

## 端到端 HTTP 性能

性能测量使用 24 种配置, HGX B200 标称速率及 [HTTP 测量流程](docs/performance.zh.md)中的参考计算.
完整计时覆盖提交, 服务准备, 推理, 采样, 传输及响应解析.
请求使用文本 greedy 生成, 不命中前缀缓存, token 预算为 32768, 最多同时运行 4 个请求.

Benchmark 使用 `http-reference-v1` 及[文档规定的假设](docs/performance.zh.md#内存).
源码 `339fa40679328caf` 已测量全部 24 种配置.
本次运行使用 1024 个 FA block, 128 个 GDN slot 和 prompt seed `nightly-dual-v1`.
表格中两个 batch 4, 8192 输出 token 的 MTP4 配置使用单独复测中较快的测量值.
它们的输入长度为 32768 和 131072 token.
