# 仓库工具

推理代码及其依赖放在其他目录中.
优先使用 Python 标准库, 必要的语法分析可使用解析器.

每个检查器仅检查其声明的契约.
使用语法树识别代码定义. 此操作不使用文本模式.

通过清晰名称和小函数表达逻辑.

hooks 和直接命令使用同一个环境 wrapper.
仅处理自有的已跟踪或未忽略文件.

不处理第三方目录, 符号链接, 生成文件和仓库外路径.
可选源码目录不存在时, 该目录没有适用文件.

适用输入有错误时, 检查必须报错并停止.
必要工具缺失时, 检查必须报错并停止.

新增测试前遵守[测试策略](../CONTRIBUTING.zh.md).
不在仓库文档中保存检查结果.
