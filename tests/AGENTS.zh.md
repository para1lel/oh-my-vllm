# 测试所有权

使用独立断言测试关键行为. 不把实现步骤复制为期望结果.
保留调度器/缓存所有权, commit/rollback, 推理草稿, 采样, 协议故障和数值边界契约.
集成或端到端测试已覆盖的常规路径不需要重复单元测试.

移动测试前, 将共享 builder 和 reference 移到 support 模块.

## 分层

目录说明职责. marker 说明运行要求; 注册 marker 并拒绝未知项.
明确选择 unit, integration, numerical, tooling 和 acceptance.
现有工具足够时, 使用小规模确定性状态/性质案例, 不增加依赖.

保留原始失败记录, 案例选择和源码身份. 不把历史证据当作当前源码验收.

## 环境与清理

使用环境包装脚本. GPU 测试通过 GPU 包装脚本使用空闲且已固定的 B200.
Agent 工作负载在可删除 sandbox 中运行, 工作目录新建, 不使用推理仓库.
测试结束后删除其中的文件, 复制或安装的工具, 容器和自有镜像.

常规端到端路径通过时, 关键故障测试仍须保留.
每次运行后停止自有 worker, 子进程和临时服务端口.
