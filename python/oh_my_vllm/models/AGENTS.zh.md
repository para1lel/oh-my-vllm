# 模型适配器

各模型族的权重, 计算, 缓存布局, 编解码器, 媒体位置, 请求状态和推测放在自己的目录中.
Qwen 与 DeepSeek 是对等适配器. 实现状态不改变其架构地位.

传输, 约束, 重复检查, 元数据上传和执行规则使用共享机制.
各适配器提供自己的工具 grammar. 不将模型维度或 token 语法放进共享机制.
显式占位实现是测试后端, 不是模型回退路径.

保持冻结的数值 fixtures 和验收限值不变.

使用[适配器契约](../../../docs/adapters.zh.md), [执行规则](../../../docs/execution.zh.md)和[测试范围](../../../docs/testing.zh.md).
将 checkpoint 和 tokenizer 身份绑定到加载的字节.
实现演进时删除无用的兼容路径和重复测试.
添加测试前, 向维护者说明已有检查为何不足.
