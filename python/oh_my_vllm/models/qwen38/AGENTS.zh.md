# Qwen 适配器

将 Qwen 权重, 缓存布局, 媒体位置, 请求状态和 MTP4 行为保留在本目录.
传输, 约束, 重复检查, 元数据上传和执行规则使用共享 worker 机制.
适配器向共享约束提供 Qwen 工具语法.
不要将 Qwen 维度或 token 语法放进共享机制.
显式占位实现是测试后端, 不是共享机制.

保持固定数值夹具及其验收门槛不变.
使用[执行规则](../../../../docs/execution.zh.md)和[测试范围](../../../../docs/testing.zh.md).
使检查点和分词器身份始终绑定已加载字节.
添加测试前, 告诉维护者其必要性.
