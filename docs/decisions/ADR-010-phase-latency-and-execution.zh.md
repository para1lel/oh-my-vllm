# ADR-010: 阶段时延与依赖执行

日期: 2026-10-09. 状态: 实现正在验收.

## 决策

Prefill 与 decode 使用逐请求框架墙钟时延.
十五项固定负载各执行两次完整预热与五次测量.
每个阶段的墙钟中位数必须不超过其理论下界中位数的三倍.
波动 `(max-min)/median` 必须不超过 10%.
固定尺寸与容量测试见 [要求](../requirements.zh.md).

从观察到的有效调度与固定模型语义推导下界.
计入参数读取, 接受与拒绝的验证行, 必需草稿工作, 采样, KV 与 recurrent state.
Padding 与实现冗余不增加下界.
使用官方单 GPU 非稀疏 B200 峰值, HBM 为 7.7 TB/s.

独立分支可以并发执行.
下界组合放松后的依赖路径与共享资源工作量.
有限理想缓存额度作用于整个资源核算区间.
当前路径放松将计算节点服务时间设为零, 并给每次读取完整缓存额度.
这些放松降低下界, 不把完整矩阵计算作为原子串行屏障.
公式, 来源链接与限制见 [时延模型](../latency-model.zh.md).

模型执行使用手动 CUDA Graph 捕获, 多个 stream 和 PDL.
捕获必须在预热后和失败时恢复持久写入.
Side stream 必须在其操作返回前汇合, 包括异常路径.
PDL consumer 在依赖读取前等待 producer.
源码, 构建输入, 已加载 binary 与运行时身份绑定执行契约.

## 影响

门槛将完整框架区间与 GPU 资源上限比较.
主机, 传输, launch 与冗余计算开销减少可用余量.
GPU event 与 profiler 计数器用于定位这些开销, 不修改理论速率.

自有 FP8 GEMM 提供 current-stream 与 PDL 控制, 保持 checkpoint 任意 FP32 group scales.
GDN 准备将独立 gate 投影与 QKVZ / 卷积分支分开执行.
Prefill graph 使用独立的有界缓存系列与 allocator topology reuse.
大型算子根据测量选择 tile 与遍历方式, 见 [性能诊断](../profiling.zh.md).

每次原始尝试保存在外部目录, 包括失败与中断.
可移植摘要标明源码和诊断 / 正式范围.
源码变化后, 必须通过数值, 容量, 服务与适用性能检查, 才能完成验收.
