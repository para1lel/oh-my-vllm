# 文档规则

遵循根目录原则的范围. 每项事实只在一个位置维护, 其他位置使用链接.
README 为使用者提供项目状态及用法. CONTRIBUTING 为贡献者提供通用流程.
根目录 AGENTS 给出共同方向. 子目录 AGENTS 描述其目录树的具体说明.

仅当目录存在专门契约时, 才添加更深层说明.

每篇自有英文 Markdown 文档的英语单词数不超过 2000.
统计可见正文, 标题, 表格内容和行内标识符. 不统计围栏代码和链接目标.
使用短句, 每段聚焦一个主题. 操作说明每句不超过 20 个词, 描述性文字每句不超过 25 个词.

描述性段落不超过 6 句. 使用简明英文和统一的技术术语.

将全部正文翻译为同目录的 `<stem>.zh.md` 对应文件.
保持事实, 条件, 不确定性, 命令, 标识符, 数字和标题层级一致.
英文是权威版本. 存在中文对应文件时, 使用其链接.
中文使用半角标点, 中文与英文或数字之间留空格.

通过源码链接提供实现细节, 避免复制.
源码行链接使用唯一文本锚点. 文档 hook 自动更新其行号.
主机路径和地址放在被忽略的本地配置中.

交接只保存当前状态和后续工作. 不添加测试结果, 日志或交付历史.
独立审查翻译含义; 自动检查无法确认语义一致.
