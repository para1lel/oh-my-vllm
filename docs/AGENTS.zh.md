# 文档所有权

使用[写作规则](writing.zh.md)和[技术术语](glossary.zh.md).
每次修改英文源文档, 同步维护同目录完整的 `<stem>.zh.md` 译文.
命令, 标识符, 数字, 证据范围和限制保持相同. 英文是权威来源.

排除第三方源码和生成的依赖内容.

## 分层披露与来源

README 提供用户设置和入口链接. 根 AGENTS 提供共同原则. 目录 AGENTS 提供局部契约.
LOCAL 提供当前主机配置和维护入口. 维护历史放在独立的被忽略记录中.
每份仓库自有英文文档最多 2000 个英文单词.

计入标题, 正文, 表格, 链接文字和行内标识符. 排除代码块, 链接地址和源码锚点元数据.
解释背景, 数学, 可观察行为和设计决策. 实现细节链接到代码.
整文件引用使用文件链接. 具体实现使用唯一文本锚点; 展示行号自动生成.

每项事实只有一个权威来源. 不重复代码中的 API 签名, 默认值或调优参数.
历史证据不得声明当前源码通过验收. 过时修复过程留在 Git 历史中.

## 检查

通过环境包装脚本运行文档检查和源码链接更新.
hook 检查本地链接, 唯一源码锚点, 单词上限和翻译契约.
reviewer 必须检查技术含义和完整翻译忠实度.

需求, 架构, 决策, 测试命令和交接的契约发生变化时同步更新.
