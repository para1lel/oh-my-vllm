# Repository collaboration

Codex uses `refactor`. OMP uses its assigned Issue branch in a different checkout.
Use the project Issues and pull requests for OMP work.

Get a code review from another agent for each milestone.
Correct the errors before publication.

Rebase the Issue branch on `refactor`.
Do the applicable checks again.
Squash the reviewed change.
Move `refactor` to the reviewed change with a fast-forward update.

The maintainer permits project Issues, OMP branches and pull requests, and publication of reviewed milestones.
Before work in other repositories or other publication, get instructions from the maintainer.
The already available TileFoundry adaptation branch is the permitted exception.

Use the [contribution procedure](../CONTRIBUTING.md) for Git revisions, hooks, and documents.
Keep host settings and ownership of temporary services in ignored local configuration.
