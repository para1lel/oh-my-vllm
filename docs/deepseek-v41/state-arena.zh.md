# 类型化状态存储所有权

## 范围

[状态 arena](../../crates/kv-cache/src/state.rs) 为阶段 2 提供类型化逻辑存储预留.
它目前不替换 Qwen 协调器.
它不分配 GPU 缓冲区, 不选择已接受的模型前缀, 也不发布 worker 结果.
[分布式接口](distributed.zh.md)提供 rank 一致性和调度器集成.
模型专属物理状态恢复是[阶段计划](plan.zh.md)中的后续工作.

## 分组和所有者

`StateArena::new` 在创建池之前验证 cache schema 和并行计划.
每个独立拥有存储的分组在每个逻辑 rank 上都有一个池.
槽位零是 null. Arena 不分配它.
每个池必须至少有一个可写槽位.

容量必须在 2 至 `u32::MAX - 2` 之间, 以便为队列哨兵留出空间.
全部独立池容量之和必须在调用者的 `max_slots` 预算内.

该预算统计逻辑槽位, 包含 null 槽位.
它不是 GPU 字节预算或测量的主机内存峰值.
Arena 验证全部池计划后, 才分配任何池存储.

共享来源描述不足以证明物理别名关系.
仅当共享视图的种类, 块单位, 格式和容量与每个生产者一致时, arena 才接受该视图.
共享视图使用同一 rank 上根生产者的池.
它不能获得独立的写分配.
通用描述符验证器保留更宽泛的结构性生产者规则.

## 预留

分配请求指定独立拥有存储的分组, rank 和正数槽位数量.
未知分组, 未知 rank, 共享写目标, 重复目标和零数量会导致错误.
Arena 在分配或固定存储之前验证全部容量和读 lease.
容量错误不能在其他分组或 rank 中留下部分预留.
新写入不使用已接受读者持有的槽位.

每个事务具有 epoch, step ID, transaction ID 和 request ID.
Epoch 必须为正数.
Step ID 必须为正数, 且在同一 arena 内不能递减.
多个事务可以使用同一个 step ID.
Transaction ID 仅在预留成功后递增.
身份计数器不会回绕.

每个池还提供递增的分配代次.
复用物理槽位会产生不同的代次.
`StateBlock` 值标识分组, rank, 槽位和代次.
这些值的副本不拥有存储, 也不能授权固定或释放存储.

## 存储选择

`StorageLease::select` 为其源 lease 持有的块创建一个 lease.
`StateTransaction::select_storage` 可以从事务的读 pin 和写槽中共同选择.
这些方法不释放或改变源所有者.
结果为每个选定块持有一个新增引用.

选择列表必须包含来自源授权块的唯一值.
每个组, rank, 槽和代次必须与某个源块一致.
共享视图组名不能替换块标识中的根 producer 名称.
结果保持传入顺序.
空选择有效, 且不持有任何槽.

这些方法在改变任何计数前验证全部选定标识和引用计数.
引用计数验证和 pin 使用同一个 arena 锁.
无效选择保持源所有者不变, 不会 pin 部分选择.

这些操作提供存储所有权.
它们不证明模型接受或设备完成.
调用方必须使正在执行的事务保持有效, 直到全部异步读写操作完成.
调用方必须在发布已接受状态前验证模型结果.

## Lease 生命周期

`StorageLease` 的所有权字段私有, 且没有 `Clone` 或反序列化实现.
它的 `pin()` 方法在引用计数验证后创建额外的读 lease.
引用计数溢出会在任何计数改变之前导致错误.
Arena 拒绝来自其他 arena 的读 lease, 即使 epoch 相同.

事务对每个读槽位仅固定一次.
重复的输入 lease 不会对同一槽位创建重复的事务固定引用.
原始请求释放其 lease 后, 这些固定引用仍保持已接受输入可用.
新写槽位具有自己的 lease.

丢弃或中止事务会释放其写槽位和读固定引用.
`into_storage()` 释放事务的读固定引用, 并将其写槽位所有权作为存储 lease 返回.
该操作不声明模型状态已被接受.
逻辑提交或前缀发布之前, 调用者必须验证模型结果及全部必要的 rank 完成情况.

调用者还必须保持事务存活, 直到异步读者和传输完成.
仅取消请求不能证明这一条件成立.
Arena 无法根据 CPU 所有权值检测设备完成情况.
调用者丢弃公开的 arena 句柄后, 存储 lease 仍保持其 arena 存活.
最后一个 lease 释放后, 其槽位才能复用.
Poisoned arena 拒绝后续分配, 且不回收可能不一致的槽位.

## 检查

小规模 Rust 检查覆盖跨组分配失败, 兼容共享视图, 读固定引用生命周期, 取消, 过期 step 和槽位代次.
它们也检查混合读/写选择, lease 生命周期, 以及不会部分 pin 的无效选择.
已有 Qwen 配对缓存测试保持不变.
这些检查不能证明分布式执行, GPU 完成, 前缀恢复或服务容量.

```bash
scripts/with-env.sh cargo test -p oh-my-vllm-kv-cache
```
